# 视频采样器（浏览器插件）

按固定间隔截取**当前标签页**的画面，自动拼成一张带时间戳的网格图并下载。
用来把 B 站 / 抖音上的教学视频「翻着看」，一屏看到多帧，比反复暂停截图快得多。

## 为什么不做「直接抓 video 元素」

视频文件在 CDN 上，跨域把 `<video>` 画进 canvas 会**污染画布**，`toDataURL` 直接抛安全错误。
所以这里用 `chrome.tabs.captureVisibleTab` 抓**可见标签页**——不受跨域限制，任何网站都能用。

## 安装（Edge / Chrome 通用）

1. 打开 `edge://extensions`（Chrome 是 `chrome://extensions`）
2. 右下角打开 **开发人员模式**
3. 点 **加载解压缩的扩展**
4. 选这个文件夹：`D:\多米\插件\video-sampler`
5. 工具栏出现「视频采样器」图标

## 使用

1. 打开视频页，把播放器切**全屏**（或至少铺满窗口）
2. 点插件图标 → 选间隔 / 张数 → **开始采样**
3. 采样期间**别切换标签页**（会截到别的页面）
4. 完成后图片在下载目录的 `视频采样/` 下，文件名带时间

建议参数：

| 场景 | 间隔 | 张数 |
|---|---|---|
| 操作演示（点按钮、放建筑） | 2~3 秒 | 16 张 |
| 整体流程过一遍 | 8~15 秒 | 9 张 |
| 只想看某一小段 | 拖到附近再点开始 | 4 张 |

## 已知限制

- 抓的是**可见区域**：播放器没铺满时，黑边和网页边栏也会进图。
- 采样期间不能做别的事：`captureVisibleTab` 截的是「当前激活标签页」。
- 只截画面，**不抓音频、不抓字幕轨道**。要字幕得另外做（B 站有 CC 字幕接口）。
- 频率受浏览器限制，最密约 2 次/秒，间隔请 ≥2 秒。

## 文件

| 文件 | 作用 |
|---|---|
| `manifest.json` | MV3 清单，权限：activeTab / tabs / downloads / scripting |
| `background.js` | 采样循环、拼网格、下载 |
| `popup.html` / `popup.js` | 参数面板与进度 |
